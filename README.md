# 月刊ぴあん（Web版）

あとりえくれよん・にじいろくれよんの「月刊ぴあん」を、保護者の方がスマホで見るためのページです。
毎月の号をためていき、過去の号もいつでも読めます。

いま載っている号：**2026年4月号〜8月号**（にじいろ2026年4月号だけ、1枚に複数課題がある以前の形式です）。
それ以前の号も共有ドライブに原本があるので、同じ手順で追加できます。

- あとりえくれよん … `index.html`
- にじいろくれよん … `nijiiro.html`

どちらのページも、上のタブでもう一方に移動できます。
ページ下の「バックナンバー」から過去の号を選べます（URL の `#2026-08` で直接開くこともできます）。

---

## 原本PDFの置き場所

共有ドライブのここが原本の保管場所です。変換スクリプトはここを見にいきます。

```
G:\共有ドライブ\あとりえくれよんＺ\②　ぴあん課題\⓪　全体\⑤　ぴあんチラシ
```

ファイル名はこの形にしてください（スクリプトがこの名前で探します）。

```
あとりえチラシ_2026年09月.pdf
にじいろチラシ_2026年09月.pdf
```

## 毎月やること（新しい号を足す）

### 1. PDFをページ画像に変換する

原本を上の場所に置いたら、**月を指定するだけ**で両事業所ぶんまとめて変換できます。

```bash
python tools/add_issue.py --ym 2026-09
```

- `--ym` は「年-月」（2026年9月号なら `2026-09`）
- 画像は `images/2026-09/atelier/p1.webp …` と `nijiiro/…` に作られます
- バックナンバー一覧に出す小さい見本（`thumb.webp`）も一緒に作られます
- 実行すると、次の手順でそのまま使える情報（ファイル名・幅・高さ）が表示されます

片方だけ・別の場所のPDFを使いたいときは：

```bash
python tools/add_issue.py --ym 2026-09 --brand nijiiro
python tools/add_issue.py --ym 2026-09 --brand nijiiro --pdf "C:\Users\...\別のファイル.pdf"
```

必要なもの: [poppler](https://github.com/oschwartz10612/poppler-windows)（`pdftoppm`）と Python の Pillow。
共有ドライブが `G:` にマウントされていないPCで作業するときは `--pdf` で直接指定してください。

### 2. `issues.js` に1件足す

`issues.js` を開き、`issues:` の配列のいちばん**先頭**に、8月号のブロックをまねて1件足します。
`src` / `w` / `h` は、手順1が表示した値をそのまま貼れます。

書く内容は、そのページが何かを表すラベルだけです。

| 項目 | 意味 | 例 |
|---|---|---|
| `sec` | ページの種類 | `cover` 表紙／`schedule` スケジュール／`subject` きょうかかだい／`meditation` めいそうかだい／`main` メインかだい／`other` 1枚に複数課題がある以前の形式 |
| `title` | 課題名 | `うちわ` |
| `sub` | 週などの補足 | `メインかだい ①週目` |
| `crop` | （任意）下半分が余白のページで、一覧のとき上から何割見せるか | `0.5` |
| `catch` | 表紙のキャッチコピー | `はなびが ドン！ こころが パッ！` |
| `note` | その月のお知らせ（無ければ空） | `8月13日・14日はお盆休みです。` |

### 3. 保存して push する

GitHub に push すると、そのまま公開ページに反映されます。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` / `nijiiro.html` | 事業所ごとの入口。中身は同じで、`data-brand` だけ違います |
| `issues.js` | **号のデータ。毎月さわるのはここだけです** |
| `assets/pian.css` | 見た目 |
| `assets/pian.js` | 号の表示と切り替え |
| `tools/add_issue.py` | PDF → ページ画像（WebP）の変換 |
| `images/2026-08/…` | 号ごとのページ画像 |
| `images/*.png`（直下） | 旧レイアウトで使っていた画像の原本。今のページからは読み込んでいません |

## つくりの方針

- **スマホ優先・親指優先**。操作は画面下の「ドック」（号えらび＋セクション移動）に集約。文字は16px以上、押すところは44px以上にしています。
- **よむ体験**。ページをタップするとフルスクリーンの「よむ画面」が開きます。よこスワイプでページ送り、ピンチ／ダブルタップで拡大、下スワイプ・✕・（Androidは戻るボタン）で閉じます。
- **号の切り替え**。ドックの「📚 ◯月号」から下にせり上がるシートで選べます。切り替えは View Transitions API（対応ブラウザ）でなめらかにつながります。
- **ホーム画面に追加できます**（PWA）。一度見た号はオフラインでも読めます（Service Worker が号の画像を端末に保存。HTML/JS は毎回ネットワーク優先なので更新はすぐ届きます）。
- **見通しのよさ**。ページの種類ごとに色とアイコンを固定し（📅スケジュール＝緑、✏️きょうか＝青、🧘めいそう＝紫、🎨メイン＝オレンジ）、いまいるセクションがドックに光ります。
- **軽さ**。ページ画像はWebP(1号あたり約1〜2MB)で、画面に入ってから読み込みます。
- **原本はPDFのまま**。ページの中身はHTMLに書き写さず画像で見せているので、書き間違いが起きません。
- 「いんさつ・PDFでほぞん」ボタンからは号ごとの印刷・PDF保存ができます。

| ファイル（追加分） | 役割 |
|---|---|
| `manifest-atelier.webmanifest` / `manifest-nijiiro.webmanifest` | ホーム画面追加（PWA）の設定 |
| `sw.js` | オフラインキャッシュ（号の画像のみキャッシュ優先） |
| `assets/icon-*.png` / `apple-touch-icon.png` | アプリアイコン（`tools/make_icons.py` で生成） |
