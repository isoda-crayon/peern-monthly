# 月刊ぴあん（Web版）

あとりえくれよん・にじいろくれよんの「月刊ぴあん」を、保護者の方がスマホで見るためのページです。
毎月の号をためていき、過去の号もいつでも読めます。

- あとりえくれよん … `index.html`
- にじいろくれよん … `nijiiro.html`

どちらのページも、上のタブでもう一方に移動できます。
ページ下の「バックナンバー」から過去の号を選べます（URL の `#2026-08` で直接開くこともできます）。

---

## 毎月やること（新しい号を足す）

### 1. PDFをページ画像に変換する

「月刊ぴあんメーカー」から書き出したPDFを、事業所ごとに1回ずつ変換します。

```bash
python tools/add_issue.py --pdf "C:\Users\...\月刊ぴあんメーカー　あとりえ.pdf" --brand atelier --ym 2026-09
python tools/add_issue.py --pdf "C:\Users\...\月刊ぴあんメーカー　にじいろ.pdf" --brand nijiiro --ym 2026-09
```

- `--ym` は「年-月」（2026年9月号なら `2026-09`）
- 画像は `images/2026-09/atelier/p1.webp …` に作られます
- バックナンバー一覧に出す小さい見本（`thumb.webp`）も一緒に作られます
- 実行すると、次の手順でそのまま使える情報（ファイル名・幅・高さ）が表示されます

必要なもの: [poppler](https://github.com/oschwartz10612/poppler-windows)（`pdftoppm`）と Python の Pillow。

### 2. `issues.js` に1件足す

`issues.js` を開き、`issues:` の配列のいちばん**先頭**に、8月号のブロックをまねて1件足します。
`src` / `w` / `h` は、手順1が表示した値をそのまま貼れます。

書く内容は、そのページが何かを表すラベルだけです。

| 項目 | 意味 | 例 |
|---|---|---|
| `sec` | ページの種類 | `cover` 表紙／`schedule` スケジュール／`subject` きょうかかだい／`meditation` めいそうかだい／`main` メインかだい |
| `title` | 課題名 | `うちわ` |
| `sub` | 週などの補足 | `メインかだい ①週目` |
| `crop` | （任意）下半分が余白のページで、一覧のとき上から何割見せるか | `0.5` |
| `catch` | 表紙のキャッチコピー | `はなびが ドン！ こころが パッ！` |
| `note` | その月のお知らせ（無ければ空） | `8月13日・14日はお盆休みです。` |

### 3. 保存して push する

GitHub に push すると、そのまま公開ページに反映されます。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` / `nijiiro.html` | 事業所ごとの入口。中身は同じで、`data-brand` だけ違います |
| `issues.js` | **号のデータ。毎月さわるのはここだけです** |
| `assets/pian.css` | 見た目 |
| `assets/pian.js` | 号の表示と切り替え |
| `tools/add_issue.py` | PDF → ページ画像（WebP）の変換 |
| `images/2026-08/…` | 号ごとのページ画像 |
| `images/*.png`（直下） | 旧レイアウトで使っていた画像の原本。今のページからは読み込んでいません |

---

## つくりの方針

- **スマホ優先**。文字は16px以上、押すところは44px以上にしています。
- **軽さ**。ページ画像はWebP（1号あたり約1〜2MB）で、画面に入ってから読み込みます。
- **見通しのよさ**。ページの種類ごとに色とアイコンを固定し（📅スケジュール＝緑、✏️きょうか＝青、🧘めいそう＝紫、🎨メイン＝オレンジ）、「いま見ている号」を常に上に表示します。
- **原本はPDFのまま**。ページの中身はHTMLに書き写さず画像で見せているので、書き間違いが起きません。
- 画像をタップすると原寸で開き、そのまま端末に保存できます。「いんさつ・PDFでほぞん」ボタンからは号ごとの印刷ができます。
